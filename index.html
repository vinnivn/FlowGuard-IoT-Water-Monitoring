INTEGRATION GUIDE

Connect your ESP32

This dashboard displays real readings only after Firebase is configured and the ESP32 begins sending heartbeats. No simulated water readings are generated.

01
Read the flow meter

ESP32 counts sensor pulses and calculates L/min and total litres.

02
Send readings over Wi-Fi

Use Firebase Realtime Database or a small API endpoint. Keep credentials private and secure database rules.

03
Subscribe from the website

The frontend listens for updated readings and refreshes the cards and chart.

The website does not connect directly to the flow meter. The ESP32 is the gateway. Device status changes to offline when its heartbeat becomes stale.
